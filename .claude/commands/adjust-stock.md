# /adjust-stock

Read stock and movements. Apply a documented count correction, with reason and unique reference.

Run `npm run erp -- adjust-stock <location> <item> <signed-quantity> <unique-reference> <reason>`. Quote names and notes. Replace placeholders with verified values. Use `--json` for analysis. If a name is ambiguous, show the candidates and stop. Report the records and any uncertainty. Never send, pay or file anything.
