# /line

Read the draft order and item. Add a line with explicit quantity, price and cost.

Run `npm run erp -- line <order> <item> <quantity> <unit-price> <unit-cost>`. Quote names and notes. Replace placeholders with verified values. Use `--json` for analysis. If a name is ambiguous, show the candidates and stop. Report the records and any uncertainty. Never send, pay or file anything.
