# /set-rate

Record an operator-verified conversion rate with its source. Never fetch or invent a live rate.

Run `npm run erp -- set-rate <NZD|AUD> <YYYY-MM-DD> <NZD-per-unit> <source>`. Quote names and notes. Replace placeholders with verified values. Use `--json` for analysis. If a name is ambiguous, show the candidates and stop. Report the records and any uncertainty. Never send, pay or file anything.
