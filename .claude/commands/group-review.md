# /group-review

Translate current open orders to indicative NZD using rates no later than the supplied date. Highlight stale or missing rates. This is not a historical order snapshot or statutory consolidation.

Run `npm run erp -- group-review [YYYY-MM-DD]`. Quote names and notes. Replace placeholders with verified values. Use `--json` for analysis. If a name is ambiguous, show the candidates and stop. Report the records and any uncertainty. Never send, pay or file anything.
