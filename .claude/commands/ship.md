# /ship

Read the order and stock. Record physically dispatched goods with a unique reference. Never infer delivery.

Run `npm run erp -- ship <line-id-or-external-id> <quantity> <unique-event-reference>`. Quote names and notes. Replace placeholders with verified values. Use `--json` for analysis. If a name is ambiguous, show the candidates and stop. Report the records and any uncertainty. Never send, pay or file anything.
