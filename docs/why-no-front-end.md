# Why there is no front end

The database holds the records. A coding agent runs documented commands for the operator. Read-only HTML views show the week and group exceptions. Branded documents print from the browser. Nothing needs a hosted web app for the demo.

A screen gives warehouse staff barcode entry, phone capture, offline queues, permissions and visual picking flows. This base does not provide those. Enterprise DNA builds the required screens and integrations into your version. The CLI is for a trusted operator with database access. Shared Postgres needs access controls and a backup plan. PGlite runs one local process at a time.
